삭제 영상 · 카빙

뷰어에서 항목을 마크·메모로 선별한 뒤, 4단계 '결과물'에서 보고서와 패키지를 생성합니다. 삭제 후보 복구·카빙은 조사된 이미지가 있을 때만 동작합니다.

외부 도구 · 감사 로그

ffmpeg/ffprobe는 영상 검증, libewf는 E01 입력, Sleuth Kit은 삭제 파일 조사에 쓰입니다. 없는 도구가 있어도 기본 폴더 분석은 동작합니다.

도구 설치: 명령 프롬프트에서 frametrace tools list

서버 연결이 끊겼습니다. frametrace-app이 실행 중인지 확인하십시오 — 자동으로 다시 연결을 시도합니다.

워크스테이션이 종료되었습니다

케이스 데이터와 감사 로그는 보존됩니다. 이 창을 닫아도 됩니다.
다시 시작하려면 frametrace-app을 실행하십시오.

시작 — 증거 넣기 · 이전 프로젝트 · 뷰어 보기

FrameTrace 사용 안내
  • 원본 증거는 읽기 전용으로만 접근합니다 — 해시·메타데이터·감사 로그 등 모든 산출물은 케이스 폴더에만 기록됩니다.
  • 순서: 증거 넣기 → 분석 → 검토(마크·선별) → 결과물(보고서·패키지). 분석한 케이스는 '이전 프로젝트'에서 다시 열 수 있습니다.
  • 도구 상태는 헤더의 '도구' 버튼을 보십시오 — E01 입력에는 libewf, 삭제 파일 조사에는 Sleuth Kit이 필요합니다. 없는 도구가 있어도 폴더 분석은 동작합니다.
  • 삭제 후보·카빙·재조립 결과는 검증을 통과하기 전까지 '후보'로만 표시됩니다.

증거 넣기

E01 이미지 파일이나 블랙박스 폴더·드라이브를 넣으면 바로 분석합니다. 원본은 읽기 전용입니다.

libewf 미설치 — E01을 분석하려면 tools/bin 또는 PATH에 ewf* 도구가 필요합니다 (헤더 '도구' 참고)

      결과물 정리 — 보고서 · 패키지
      
    
      검토가 끝나면 결과 보고서를 생성합니다. 보고서에는 발견된 원본 영상, 메타데이터, SHA-256 해시, 발견/분석 기법, 처리 체인이 정리됩니다. 최종 패키징은 색인된 원본 파일의 SHA-256을 다시 계산해 기록된 값과 비교하고, 일치/불일치를 보고서에 그대로 기록합니다 (불일치의 원인은 판단하지 않습니다).
