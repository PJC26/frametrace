로컬 전용 · 원본 증거는 읽기 전용으로만 접근합니다
서버 연결이 끊겼습니다. frametrace-app이 실행 중인지 확인하십시오 — 자동으로 다시 연결을 시도합니다.

워크스테이션이 종료되었습니다

케이스 데이터와 감사 로그는 보존됩니다. 이 창을 닫아도 됩니다.
다시 시작하려면 frametrace-app을 실행하십시오.

새 분석 — 증거 입력

FrameTrace 첫 실행 안내
  • 원본 증거는 읽기 전용으로만 접근합니다 — 해시·메타데이터·감사 로그 등 모든 산출물은 아래 '케이스 폴더'에만 기록됩니다.
  • 진행은 왼쪽 4단계를 따릅니다: ① 입력 → ② 분석 → ③ 검토(마크·선별) → ④ 결과물(보고서·패키지)
  • 도구 상태는 헤더 배지를 보십시오 — ffmpeg/ffprobe는 영상 검증에 쓰이고, E01 입력에는 libewf, 삭제 파일 조사에는 Sleuth Kit이 필요합니다. 없는 도구가 있어도 기본 폴더 분석은 동작합니다.
  • 삭제 후보·카빙·재조립 결과는 검증을 통과하기 전까지 '후보'로만 표시됩니다.
  • 첫 행동: 증거 소스 경로를 입력하고 '분석 시작'을 누르십시오.
이 안내는 한 번만 표시됩니다 — 아래 '안내 다시 보기'로 언제든 다시 열 수 있습니다.
이전 세션의 케이스가 복원되었습니다
  • 케이스:
  • 마지막 검토 상태가 그대로 남아 있습니다 — 이어서 검토하거나 새 분석을 시작할 수 있습니다.

분석할 증거를 선택하십시오. 원본은 읽기 전용으로만 접근되며 모든 산출물은 케이스 폴더에 생성됩니다.

분석 모드
분석에는 소스 크기에 따라 수 분이 걸릴 수 있습니다.

이미 만들어진 케이스가 있으면 케이스 폴더를 지정한 뒤 로 검토 화면을 바로 열 수 있습니다.
브라우저를 닫은 경우 frametrace-app을 다시 실행하면 이 화면으로 돌아옵니다.

분석 진행

    결과물 정리 — 보고서 · 패키지
    
    
    검토가 끝나면 결과 보고서를 생성합니다. 보고서에는 발견된 원본 영상, 메타데이터, SHA-256 해시, 발견/분석 기법, 처리 체인이 정리됩니다. 최종 패키징은 색인된 원본 파일의 SHA-256을 다시 계산해 기록된 값과 비교하고, 일치/불일치를 보고서에 그대로 기록합니다 (불일치의 원인은 판단하지 않습니다).
