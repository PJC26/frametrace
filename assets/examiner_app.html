    외부 도구 · 감사 로그

    없는 도구가 있어도 폴더 분석은 동작합니다. E01에는 libewf, 삭제 파일 조사에는 Sleuth Kit이 필요합니다. [설치]를 누르면 자동으로 받아 설치합니다.

    사용 안내
    • 원본 증거는 읽기 전용으로만 읽고, 모든 산출물은 케이스 폴더에 기록합니다.
    • 증거 넣기 → 분석 → 검토(마크) → 결과물(보고서·패키지).
    • 삭제 후보·카빙 결과는 검증을 통과하기 전까지 ‘후보’로만 표시됩니다.
    • Alt+P 프로젝트 · Alt+J 작업 · Alt+R 결과물
    서버 연결 끊김 — 재연결 중 frametrace-app이 실행 중인지 확인하십시오. 화면과 판독 내용은 그대로 유지되고, 연결되면 자동으로 이어집니다.

    시작 — 증거 넣기 · 이전 프로젝트

    증거 넣기

    E01 이미지 파일이나 블랙박스 폴더·드라이브 경로를 넣으면 종류를 알아서 판별해 분석합니다.

    경로를 붙여넣거나 파일을 이 카드에 끌어다 놓으십시오. 탐색기에서 파일을 Shift+우클릭 → ‘경로로 복사’ 후 Ctrl+V 하면 가장 빠릅니다 (따옴표는 자동으로 지웁니다).
