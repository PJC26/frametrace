# 3단계 계획 — 전체 리뷰 잔여 항목 (2026-10-13, 통합자 작성)

기준: `docs/FULL_REVIEW_2026-10-13.md`. 1단계(U1·U2·U3·I1·I2·I3 + R1 후속)와 2단계(이어붙이기·소리)에서 이미 처리된 것은 제외. omo·Fable 사용 불가로 통합자가 직접 작성, 구현은 Opus/Sonnet.

공통 규칙: CLAUDE.md 게이트 · 주석 무손실 · 조용한 실패 금지 · 보고서는 검증한 것만 · 단축키 보존 · state_lock 아래에서 디스크/DB/외부 도구 작업 금지 · 테스트는 실제 사용자 설정을 건드리지 않음 · 고정 sleep 금지.
