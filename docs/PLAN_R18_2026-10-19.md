# 18라운드 수정 계획 — 17라운드 적대적 리뷰 (2026-10-19, 기준 891f180)

## 0. 상황
17라운드 리뷰: Blocker 0. **High 1(PowerShell 스마트 따옴표 명령 주입, PoC)**, Medium 3(뷰어 이상 후보 회귀 PoC-B, mixed-version 우회 PoC-A, withheld가 실제 불일치를 가림 PoC), Low 다수. 모두 고친다.

> **P29. 붙여넣는 명령은 안전하거나 없다.** 사용자에게 붙여넣으라고 주는 명령 문자열은 경로에 셸이 해석할 수 있는 문자(PowerShell 작은따옴표 계열 ' ‘ ’ ‚ ‛, 제어문자, cmd `%`·`!`·`^`·`&`·`|`·`<`·`>`·`"`)가 있으면 만들지 않는다(null + "직접 입력" 안내). 화이트리스트(안전 문자만)로 판정한다.
> **P30. 경고성 데이터는 안전한 쪽으로 센다.** 이상 징후처럼 "있으면 나쁜" 표시는 인증 안 됨·대체됨 행도 개수에 포함하고 표시만 구분한다. 빠진 줄이 표시를 좋게 만들지 않는다.
> **P31. 모르면 차단 가능으로.** 상태 화면이 판정을 보류할 때(`withheld`)는 `blocks_finalize: null`(모름)이고, 기억된 복구 판정이 있으면 그것을 보인다.

공통 규칙은 `PLAN_R4_2026-10-14.md` §0.
