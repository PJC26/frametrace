# 13라운드 수정 계획 — 12라운드 적대적 리뷰 (2026-10-16, 기준 49491f2)

## 0. 원칙 확장
R12의 저널(P13)은 어떤 키에도 묶이지 않아, 케이스 폴더에 쓰기 권한만 있으면 워크스테이션이 **스스로** 완료된 서명을 포기하고 되돌리게 만들 수 있었다(High, PoC 재현). P12는 "표식 뒤의 사용 불가 줄"만 보류했고, **표식 자체를 지운** 경우(서명 불필요)는 이전 실행이 결과가 됐다.

> **P15. 복구 동작은 키 서명된 레인 기록과 짝이 맞을 때만.** 최종화 시작(`finalize-begin`: 이전 서명 SHA, 예약 패키지 이름, 호스트 ID)과 완료(`finalize-complete`: 서명 SHA, 패키지 manifest SHA)를 서명 레인의 키 항목으로 남긴다. 저널은 위치 단서일 뿐이며, 레인에 짝이 없는 저널(또는 키가 있는데 인증 안 된 저널)은 아무것도 바꾸지 않고 "확인 필요"만 표시한다. 복원 바이트는 레인에 기록된 이전 SHA와 같을 때만 쓴다. 완료 항목이 있으면 저널만 지운다.
> **P16. 결과 실행 뒤의 사용 가능한 미완료 실행도 결과를 보류한다.** 표식이 지워진 더 새 실행의 사용 가능한 `mismatch` 줄은 숨기지 않고 표시한다. 수리 표식 뒤는 모든 "최신 기록" 소비자가 "알 수 없음"으로 처리한다.
> **P17. 다른 호스트의 미완료 작업은 건드리지 않는다.** 저널·레인 항목에 호스트 ID를 기록하고, 다른 호스트 것은 차단만(24 h) 하며 명시 확인 없이는 복구하지 않는다. 시작 시 복구는 서빙 뒤 백그라운드(busy 보유, status "복구 중").

공통 규칙은 `PLAN_R4_2026-10-14.md` §0.
