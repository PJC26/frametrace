## 1. 최종 사용자
- **주 사용자: 영상 포렌식 검수자(수사관·감정인, 한국어).** 수 TB 블랙박스/CCTV/SD/HDD를 받아 사건 시각의 영상을 찾고, 구간을 잘라 증거로 내고, 법정에서 방어 가능한 보고서를 낸다.
- 상태: 피곤, 시간 압박, 반복 작업. 실수 하나(오타 키, 포트 변경, 오래 걸린 작업 실패)가 수시간 작업 손실로 이어진다.
- 간접 사용자: 보고서 읽는 판사·변호인(과장된 주장에 취약), 다른 프로그래머(CLI/계약 소비).

## 2. 이상 상태 (반드시 이렇게 느껴져야 함)
1. 아무 키/버튼도 **조용히 죽지 않는다** — 모든 실패는 보이고 복구 가능하다. (이유: 증거 도구에서 침묵 실패 = 신뢰 상실)
2. **라벨/메모는 절대 사라지지 않는다** — 저장 상태가 항상 보이고, 실수는 Undo 된다. (이유: 수시간 판독 결과)
3. 긴 작업은 **진행·취소·재개**가 있다. 첫 화면까지 기다리지 않는다.
4. 브라우저 단축키(Ctrl+0 등)가 주석을 파괴하지 않는다. Space=재생/일시정지.
5. 보고서는 **검증한 것만 주장**한다(관측/휴리스틱 구분). 최종화 전 체크리스트.
6. 서버는 localhost 한정에서도 임의 경로 열기·실행형 MIME 제공을 하지 않는다.
7. 빌드/테스트/CI가 로컬과 동일하게 통과, UI 변화는 스크린샷으로 확인 가능.
