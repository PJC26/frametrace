# 4라운드 수정 계획 — 전체 적대적 리뷰 3차 (2026-10-14, 기준 6f227af)

리뷰 5영역 + 무결성 하위 리뷰 3건(파서·스캔·카빙 / 이어붙이기·소리·감사·서명 / 보고서·패키지·가림)의 결과 전부를 고친다. 작성: 통합자(Opus, Fable·omo 사용 불가). 구현: Opus(어려움·보통), Sonnet(테스트·문서).

## 0. 공통 규칙
- CLAUDE.md 게이트 전부 + 이 문서 §8의 추가 게이트.
- 주석(마크·메모·태그·IN/OUT) 무손실, 조용한 실패 금지, 보고서는 검증한 것만 주장.
- `state_lock` 아래에서 디스크·DB·외부 도구 작업 금지(`FRAMETRACE_DEBUG_LOCKS=1`로 확인).
- 단축키·UI 규칙 보존. 테스트는 실제 사용자 설정을 건드리지 않음. 고정 sleep 금지.
- 각 수정에는 **수정 전 코드에서 실패하는 테스트**를 붙인다(불가능하면 이유를 보고).
- Linux·macOS 컴파일 안전: Windows 전용 순수 헬퍼는 `#[cfg_attr(not(windows), allow(dead_code))]`, 테스트는 경로 의미를 플랫폼별로.
- 파일 소유권은 §7 표를 따른다. 남의 파일이 필요하면 "통합 TODO"로 보고(정확한 변경 내용 포함).
